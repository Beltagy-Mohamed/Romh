# فزعة رمح — Faza'a Rmaah

نظام استغاثة قبلي: نداء بضغطة واحدة يصل بالتدرج إلى أنسب المستجيبين، مع حالة لحظية وخصوصية على مرحلتين.

> المرجع: وثيقة المواصفات v1.1 (مسودة 2026-10). القرارات المُعتمدة تجدها في `docs/DECISIONS.md`.

## المبادئ الحاكمة (تنطبق على كل قرار تقني)

1. الموثوقية قبل المزايا — وصول التنبيه أهم من أي شيء.
2. الخصوصية بالتدرج — لا موقع دقيق ولا هاتف إلا بعد «أبشر».
3. توجيه ذكي لا بث شامل.
4. مكمّل للجهات الرسمية — لا يُلغيها.
5. مساءلة كاملة — كل إجراء إداري في سجل append-only.
6. لا حشد جماعي في الخلافات.

## البنية

| الجزء | التقنية | الحالة في هذا المخزون |
|---|---|---|
| الخادم | NestJS + PostgreSQL/PostGIS + Redis + BullMQ + Socket.IO | هيكل عامل (Phase 1 core) |
| الموبايل | Flutter (Android + PWA/Web) | شاشات حرجة + هياكل الخدمات |
| لوحة الأدمن | ويب منفصل (مخطط: Vite + React) | لم يُبنَ بعد — راجع خارطة الطريق |
| قاعدة البيانات | SQL migrations بما فيها RLS | مكتملة للمرحلة 1 |

## التشغيل السريع

المتطلبات: Docker Desktop + Node 22+.

```bash
# 1) البنية التحتية (قاعدة بيانات + Redis)
docker compose up -d postgres redis

# 2) الخادم
cd apps/api
npm install
cp .env.example .env          # عدّل القيم عند الحاجة
npm run migrate               # ينشئ المخطط + RLS + البيانات الأولية
npm run start:dev             # http://localhost:3000/api/v1
```

للتطبيق الموبايل: `cd apps/mobile` بعد تثبيت Flutter SDK (`flutter doctor`) ثم `flutter pub get; flutter run`. نسخة PWA: `flutter build web` وتُقدَّم من `/web`.

## خارطة الطريق (مطابقة القسم 20 من الوثيقة)

- **المرحلة 1 (هذا المخزون):** schema كامل، مصادقة OTP، إنشاء بلاغ بإرسال فوري، محرك الدوائر 1-3 على BullMQ، الخصوصية على مرحلتين (API + RLS)، أزرار الاستجابة الثلاثة، العدّاد والموقع الحي، الإغلاق وunresponsive، أرقام الطوارئ، سجل العمليات (hash chain)، PIN الإلغاء/الإكراه.
  - المتبقي في المرحلة 1: FCM الفعلي + مزود SMS (بوابتان stub جاهزتان)، اختبار إشعار إلزامي، شاشات Flutter المتبقية (التزكية، القدرات، الإعدادات).
- **الإصدار 1.1:** اختيار المزكّين تلقائيًا («أقرب الأعضاء»)، الحظر وسلسلته، شجرة رمح، widget واختصارات، وضع التدريب، توثيق الأطباء، لوحة الأدمن الكاملة.
- **الإصدار 2:** خرائط دون إنترنت، الساعات الذكية، التحليلات.
